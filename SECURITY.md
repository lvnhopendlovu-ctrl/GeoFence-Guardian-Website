# Security policy

## Reporting a website vulnerability

Do not publish credentials, personal information, precise locations, or an actively exploitable vulnerability in a public Issue or Discussion.

Use the contact route on the [support page](https://geofenceguardians.co.za/support/) and clearly label the report as a security concern without including exploit details in the public title. If a private reporting channel becomes available, this file will be updated.

Include only what is safe to share:

- Affected URL or component
- Browser and operating system
- High-level impact
- Whether the issue is reproducible
- A safe way to request further details

## Scope

This repository contains the public static website. Android application vulnerabilities, lost devices, account compromise, payment disputes, and emergencies require their appropriate support or emergency channels.

## Supported version

Only the currently deployed website on `main` is supported.
