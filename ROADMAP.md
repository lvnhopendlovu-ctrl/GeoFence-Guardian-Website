# Public roadmap

The roadmap is intentionally outcome-focused. It is not a promise of release dates.

## Now

- Keep the website, guides, privacy statements, and release information accurate
- Improve accessibility and mobile usability based on reproducible reports
- Expand practical safety tools without collecting visitor accounts or form submissions
- Maintain reliable GitHub Pages deployment and live-site checks

## Next

- Add more device-preparation and incident-response guides when primary sources support them
- Improve downloadable safety resources and printable formats
- Add translations when a review process can preserve safety accuracy
- Publish clearer compatibility notes for Android versions and manufacturers

## Exploring

- Community-contributed safety checklists for campuses and travel
- A versioned public product-permission ledger
- More transparent, reproducible reliability documentation

## Not planned

- Advertising trackers or sale of visitor data
- Accounts solely for accessing website tools
- Unsupported claims that software can guarantee theft prevention or device recovery
- Publishing private Android signing material or user location information

Feature ideas are welcome in GitHub Discussions. Reproducible defects belong in Issues.
