# Contributing

Thank you for helping improve GeoFence Guardian's public website and safety resources.

## Before opening an issue

1. Check existing Issues and Discussions.
2. Reproduce website bugs in a current browser.
3. Remove location details, credentials, account identifiers, and other sensitive information.
4. For safety guidance, link to a current primary source such as official Android or service-provider documentation.

## Pull requests

- Keep changes focused and explain the visitor problem they solve.
- Preserve the privacy-first design: browser tools should not transmit personal input without an explicit, documented reason.
- Do not add advertising, behavioural tracking, fingerprinting, or unnecessary third-party scripts.
- Run `npm run lint` and `npm run build` before requesting review.
- Do not include generated build output, credentials, keystores, APKs, or Android signing material.

## Content standards

- Do not invent testimonials, user counts, ratings, crime statistics, or product capabilities.
- Distinguish illustrative web simulations from real Android behaviour.
- Use calm, practical language and avoid fear-based marketing.
- Treat safety, privacy, and recovery claims as accuracy-sensitive.

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
